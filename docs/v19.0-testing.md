# ZoneMinder v19 acceptance crosswalk

The v19 appliance installs the official ZoneMinder 1.38.4 Trixie package at an exact version and SHA256 digest. The source record retains the package URL, digest, repository channel, and signing-key fingerprint.

`tests/v19.sh` checks the normal appliance path: authenticated HTTPS web-console and API login with the firstboot application password, including ZoneMinder's intermediate browser post-login session step; creation and API readback of one non-hardware monitor; an authenticated enable-state update; MariaDB readback; persistence after a ZoneMinder restart; and fixture cleanup. It also checks Apache, MariaDB, ZoneMinder, and Postfix service state, the Adminer and Webmin HTTPS endpoints, and the supervised stable-channel updater.

## Exact-run status

The first exact Wave 2 execution built, imported, and completed firstboot/runtime health successfully. Its web-login check stopped on ZoneMinder's JavaScript-driven intermediate post-login page before the authenticated console and API checks; that test-only assertion defect is fixed here and consumes no product loop. An exact retry is pending on the isolated Wave 2 builder.

## Deferred boundaries

Camera capture and motion detection require hardware or a representative media stream, so the bounded acceptance fixture uses a disabled FFmpeg monitor. The test proves authenticated monitor management without claiming hardware capture coverage.
