# ZoneMinder v19 acceptance crosswalk

The v19 appliance installs the official ZoneMinder 1.38.4 Trixie package at an exact version and SHA256 digest. The source record retains the package URL, digest, repository channel, and signing-key fingerprint.

`tests/v19.sh` checks the normal appliance path: authenticated HTTPS web-console and API login with the firstboot application password, creation and API readback of one non-hardware monitor, an authenticated enable-state update, MariaDB readback, persistence after a ZoneMinder restart, and fixture cleanup. It also checks Apache, MariaDB, ZoneMinder, and Postfix service state, the Adminer and Webmin HTTPS endpoints, and the supervised stable-channel updater.

## Exact-run status

Exact Wave 2 execution is queued behind the other migrations on the isolated Wave 2 builder. No product loop has been consumed; the candidate currently has primary-source provenance and static boundary validation only.

## Deferred boundaries

Camera capture and motion detection require hardware or a representative media stream, so the bounded acceptance fixture uses a disabled FFmpeg monitor. The test proves authenticated monitor management without claiming hardware capture coverage.
