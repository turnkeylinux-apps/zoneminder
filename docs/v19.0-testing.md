# ZoneMinder v19 acceptance crosswalk

The v19 appliance installs the ZoneMinder package provided by Debian Trixie. The source record retains the suite and installed package version, while apt verifies package integrity through Debian archive signatures.

`tests/v19.sh` checks the normal appliance path: HTTPS console rendering, admin API login with the firstboot application password, creation and API readback of one disabled non-hardware monitor, MariaDB readback, persistence after a ZoneMinder restart, and fixture cleanup. It also checks Apache, MariaDB, ZoneMinder, and Postfix service state, the Adminer and Webmin HTTPS endpoints, and the exact Trixie package sources reported for the installed and candidate versions. The documented package update path runs `zmupdate.pl`, restarts ZoneMinder, and checks the application over HTTPS.

Core 19 evidence covers the inherited operating-system identity, boot path, SSH, and unchanged Core services. The appliance test directly checks ZoneMinder together with the configured TLS, Webmin, Adminer, and Postfix integration.
